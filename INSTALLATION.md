# Быстрая установка RFA to IFC4 Converter

## Шаг 1: Установите pyRevit

1. Скачайте: https://github.com/eirannejad/pyRevit/releases
2. Запустите установщик
3. Перезапустите Revit

## Шаг 2: Установите расширение

### Автоматическая установка (рекомендуется)

1. Откройте командную строку (cmd) или PowerShell
2. Выполните команду:
   ```bash
   pyrevit extend ui RFAtoIFC https://github.com/your-repo/convector.git
   ```
3. Перезагрузите pyRevit в Revit

### Ручная установка

1. Найдите папку расширений pyRevit:
   ```
   %APPDATA%\pyRevit\Extensions
   ```
   Полный путь обычно:
   ```
   C:\Users\<ВашеИмя>\AppData\Roaming\pyRevit\Extensions
   ```

2. Скопируйте папку `RFAtoIFC.extension` в эту директорию:
   ```
   C:\Users\<ВашеИмя>\AppData\Roaming\pyRevit\Extensions\RFAtoIFC.extension\
   ```

3. Откройте Revit

4. На вкладке **pyRevit** нажмите **Reload** (иконка с круговыми стрелками)

5. После перезагрузки появится новая вкладка **RFAtoIFC**

## Шаг 3: Подготовьте шаблоны

Создайте 5 проектов Revit (.rvt):

### 1. Проект со стеной (Wall_Template.rvt)
- Создайте стену: Architecture → Wall → Rectangular (6000 x 3000 мм)
- Используйте тип: Generic - 200mm
- Сохраните проект

### 2. Проект с полом (Floor_Template.rvt)
- Создайте пол: Architecture → Floor → Rectangular (6000 x 6000 мм)
- Используйте тип: Generic - 150mm
- Сохраните проект

### 3. Проект с потолком (Ceiling_Template.rvt)
- Создайте комнату с помощью Room tool
- Создайте потолок: Architecture → Ceiling → Automatic Ceiling
- Размер: 6000 x 6000 мм
- Сохраните проект

### 4. Проект с крышей (Roof_Template.rvt)
- Создайте крышу: Architecture → Roof → Roof by Footprint
- Размер: 6000 x 6000 мм
- Сохраните проект

### 5. Пустой проект (Empty_Template.rvt)
- Создайте новый проект (Architectural Template)
- Убедитесь, что есть хотя бы один Level
- Сохраните проект

**Рекомендуемая структура папок:**
```
C:\Revit Templates\
└── RFA Conversion\
    ├── Wall_Template.rvt
    ├── Floor_Template.rvt
    ├── Ceiling_Template.rvt
    ├── Roof_Template.rvt
    └── Empty_Template.rvt
```

## Шаг 4: Настройте расширение

1. Откройте Revit
2. Перейдите на вкладку **RFAtoIFC**
3. Нажмите кнопку **Settings** (⚙️)
4. Укажите пути к каждому из 5 шаблонов
5. Нажмите **Сохранить**

## Шаг 5: Готово!

Теперь вы можете конвертировать RFA файлы:

1. Нажмите кнопку **ConvertRFA** (🔄)
2. Выберите файл или папку с .rfa файлами
3. Выберите папку для экспорта
4. Дождитесь завершения

Результаты будут сохранены в папке `IFC4` внутри выбранной директории.

## Проверка установки

### Проверьте, что расширение установлено:

1. Откройте Revit
2. Вы должны увидеть вкладку **RFAtoIFC** в ленте
3. На вкладке должна быть панель **Convert** с двумя кнопками:
   - **Settings** (⚙️)
   - **ConvertRFA** (🔄)

### Проверьте работу:

1. Создайте простое семейство (например, Generic Model)
2. Сохраните как .rfa файл
3. Нажмите **ConvertRFA**
4. Выберите этот файл
5. Выберите папку экспорта
6. Проверьте, что IFC файл был создан в папке `IFC4`

## Устранение проблем

### Вкладка RFAtoIFC не появляется

**Решение:**
1. Убедитесь, что папка `RFAtoIFC.extension` находится в правильной директории
2. Проверьте структуру папок (должна быть: `RFAtoIFC.extension/RFAtoIFC.tab/...`)
3. Нажмите **pyRevit → Reload**
4. Если не помогло, перезапустите Revit

### Ошибка при запуске скрипта

**Решение:**
1. Откройте **pyRevit → Settings → Core**
2. Убедитесь, что включена опция "Load Beta Tools"
3. Проверьте консоль pyRevit для деталей ошибки
4. Убедитесь, что у вас установлена правильная версия pyRevit (4.8.12+)

### "Шаблоны не настроены"

**Решение:**
1. Нажмите **Settings**
2. Укажите пути ко всем 5 шаблонам
3. Убедитесь, что файлы существуют и доступны
4. Нажмите **Сохранить**

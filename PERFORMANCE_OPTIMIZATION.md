# Оптимизация производительности RFA to IFC4 Converter

## 🚀 Ускорение работы скрипта

Этот документ описывает способы ускорения конвертации RFA файлов в IFC4.

---

| Режим | Скорость | Память | Качество | Рекомендация |
|-------|----------|--------|----------|--------------|
| **Standard** | 1x | Низкое | Высокое | <100 файлов |
| **Fast (кэш)** | **3-5x** | Среднее | Высокое | 100-1000 файлов |
| **Fast + Low Quality** | **5-10x** | Среднее | Среднее | >1000 файлов или для превью |

## ⚡ Способы ускорения

### 1. **Кэширование шаблонов (САМОЕ ВАЖНОЕ!)**

**Проблема:** Стандартный скрипт открывает и закрывает шаблоны для каждого файла.
```
Файл 1: Открыть шаблон → Обработка → Закрыть
Файл 2: Открыть шаблон → Обработка → Закрыть  ← Медленно!
Файл 3: Открыть шаблон → Обработка → Закрыть
```

**Решение:** Загрузить шаблоны один раз и использовать повторно.
```
Загрузить все шаблоны один раз
Файл 1: Использовать кэш → Обработка  ← БЫСТРО!
Файл 2: Использовать кэш → Обработка
Файл 3: Использовать кэш → Обработка
Закрыть все шаблоны
```

**Ускорение:** 3-5x
**Память:** +500-1000 MB (зависит от размера шаблонов)

**Использование:**
1. Используйте кнопку **ConvertRFA_Fast** вместо ConvertRFA
2. При запросе выберите **ДА** для режима с кэшированием

---

### 2. **Упрощенное размещение семейства**

**Проблема:** Стандартный скрипт размещает instance семейства с учетом host-элементов.

**Решение:** Для экспорта достаточно только активировать FamilySymbol.

```python
# МЕДЛЕННО (стандартный):
- Найти host элемент (стену/пол)
- Вычислить точку размещения
- Создать instance на host
- Настроить параметры

# БЫСТРО (оптимизированный):
- Активировать symbol
```

**Ускорение:** 20-30% на файл
**Качество:** Без изменений (для экспорта достаточно)

---

### 3. **Настройка качества экспорта IFC**

#### Три режима качества:

**FAST** - максимальная скорость
```python
quality='fast'
TessellationLevelOfDetail = 0.2    # Очень грубая детализация
UseCoarseTessellation = True       # Грубая триангуляция
ExportBaseQuantities = False       # Без дополнительных данных
```
- Ускорение: 2-3x
- Размер файла: -50-70%
- Подходит для: Превью, быстрого просмотра

**MEDIUM** - баланс (по умолчанию)
```python
quality='medium'
TessellationLevelOfDetail = 0.4    # Средняя детализация
UseCoarseTessellation = False
ExportSurfaceStyles = True         # Материалы сохраняются
```
- Ускорение: 1.5-2x
- Размер файла: стандартный
- Подходит для: Blender, визуализация

**HIGH** - максимальное качество
```python
quality='high'
TessellationLevelOfDetail = 0.6    # Высокая детализация
ExportIFCCommonPropertySets = True # Все свойства
```
- Ускорение: 1x (базовая скорость)
- Размер файла: +30-50%
- Подходит для: BIM-координация, точные модели

### 4. **Оптимизация шаблонов проектов**

Создайте **легкие** шаблоны:

#### ❌ Плохо (медленный шаблон):
- Много видов (планы, разрезы, 3D)
- Сложные семейства в шаблоне
- Загруженные материалы и текстуры
- Фильтры видимости
- Design Options

#### ✅ Хорошо (быстрый шаблон):
- Только 1 уровень
- Только 1 3D-вид
- Простой host-элемент (стена/пол)
- Минимум материалов
- Нет лишних семейств

**Создание оптимального шаблона:**
```
1. File → New → Architectural Template
2. Удалите все лишние виды (оставьте 1 3D-вид)
3. Создайте базовый элемент:
   - Стена: 6000 x 3000 мм (Generic - 200mm)
4. Удалите все лишние семейства
5. Save As → Wall_Template_Fast.rvt
```

**Ускорение:** 30-50% при загрузке шаблона

### 6. **Настройка Windows и Revit**

#### Оптимизация Windows:
```
- Отключите антивирус для папки с RFA (временно)
- Используйте SSD для временных файлов
- Освободите RAM (закройте лишние программы)
- Отключите индексацию для папки экспорта
```

#### Оптимизация Revit:
```
Revit Options:
- Graphics: Performance → Отключите тени
- View: Detail Level → Coarse
- Hardware Acceleration → Включите
- Отключите Worksharing если не используете
```

## 🛠️ Инструменты оптимизации

### Скрипт предпроверки файлов

Создайте файл `check_rfa_files.py`:

```python
# -*- coding: utf-8 -*-
"""Quick check for RFA files before conversion."""

import os
import sys

def check_rfa_library(folder_path):
    """Check all RFA files in folder.

    Returns:
        good_files: List of files ready for conversion
        skip_files: List of files to skip with reasons
    """
    good_files = []
    skip_files = []

    for root, dirs, files in os.walk(folder_path):
        for file in files:
            if not file.lower().endswith('.rfa'):
                continue

            filepath = os.path.join(root, file)
            filesize = os.path.getsize(filepath) / (1024.0 * 1024.0)  # MB

            # Skip very large files (>50 MB)
            if filesize > 50:
                skip_files.append((file, "Too large: {:.1f} MB".format(filesize)))
                continue

            # Skip files with specific patterns
            if any(pattern in file.lower() for pattern in ['_backup', '_old', 'temp_']):
                skip_files.append((file, "Backup or temp file"))
                continue

            good_files.append(filepath)

    return good_files, skip_files


def main():
    library_path = "C:/Revit Families"  # Замените на свой путь

    print("Проверка библиотеки: {}".format(library_path))
    print("-" * 60)

    good_files, skip_files = check_rfa_library(library_path)

    print("\n✓ Файлов готовых к конвертации: {}".format(len(good_files)))
    print("⚠ Файлов пропущено: {}".format(len(skip_files)))

    if skip_files:
        print("\nПропущенные файлы:")
        for filename, reason in skip_files[:20]:  # Показать первые 20
            print("  - {}: {}".format(filename, reason))
        if len(skip_files) > 20:
            print("  ... и еще {} файлов".format(len(skip_files) - 20))

    # Сохранить список хороших файлов
    output_file = os.path.join(library_path, "files_to_convert.txt")
    with open(output_file, 'w') as f:
        for filepath in good_files:
            f.write(filepath + '\n')

    print("\nСписок файлов сохранен: {}".format(output_file))


if __name__ == '__main__':
    main()
```

## 📊 Мониторинг производительности

Скрипт **ConvertRFA_Fast** показывает статистику:

```
ИТОГИ КОНВЕРТАЦИИ
============================================================
Всего файлов: 150
Успешно: 147
Ошибок: 3

Время работы: 25.3 мин
Среднее время на файл: 10.1 сек

Распределение времени:
  open_family: 15.2% (230s)      ← Время на открытие семейств
  load_template: 8.5% (129s)     ← Загрузка шаблонов (с кэшем - 0%)
  load_family: 22.3% (338s)      ← Загрузка в проект
  place_instance: 5.0% (76s)     ← Размещение
  export_ifc: 49.0% (743s)       ← Экспорт IFC (самое долгое)
```

**Анализ:**
- Если `load_template` > 10% → включите кэширование
- Если `export_ifc` > 60% → уменьшите качество экспорта
- Если `open_family` > 25% → файлы слишком большие

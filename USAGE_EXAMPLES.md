# Примеры использования RFA to IFC4 Converter

## Базовые сценарии

### Сценарий 1: Конвертация одного файла

**Задача:** Конвертировать одну дверь (Door_01.rfa) в IFC4 для импорта в Blender.

**Шаги:**
1. Откройте Revit
2. RFAtoIFC → ConvertRFA
3. Выберите "Выбрать файл .rfa"
4. Найдите файл: `C:\Families\Doors\Door_01.rfa`
5. Выберите папку экспорта: `C:\Export`
6. Дождитесь завершения

**Результат:**
```
C:\Export\
└── IFC4\
    └── Door_01.ifc
```

**Время:** ~10-30 секунд на файл

---

### Сценарий 2: Пакетная конвертация всей библиотеки

**Задача:** Конвертировать всю библиотеку семейств мебели (150 файлов) для использования в Blender.

**Шаги:**
1. Организуйте файлы:
   ```
   C:\Revit Families\
   ├── Furniture\
   │   ├── Chairs\
   │   │   ├── Chair_01.rfa
   │   │   ├── Chair_02.rfa
   │   │   └── ...
   │   ├── Tables\
   │   │   ├── Table_01.rfa
   │   │   └── ...
   │   └── Cabinets\
   │       └── ...
   ```

2. RFAtoIFC → ConvertRFA
3. Выберите "Выбрать папку с .rfa файлами"
4. Выберите: `C:\Revit Families\Furniture`
5. Выберите папку экспорта: `C:\Export\Furniture_IFC`
6. Дождитесь завершения (может занять время)

**Результат:**
```
C:\Export\Furniture_IFC\
└── IFC4\
    ├── Chair_01.ifc
    ├── Chair_02.ifc
    ├── Table_01.ifc
    └── ... (все 150 файлов)
```

**Время:** ~15-45 минут для 150 файлов (зависит от сложности семейств)

**Совет:** Проверьте консоль pyRevit для отслеживания прогресса.

### Сценарий 3: Конвертация семейств разных типов

**Задача:** Конвертировать коллекцию, содержащую разные типы семейств (окна, двери, мебель, светильники).

**Структура:**
```
C:\Mixed_Families\
├── Windows\
│   ├── Window_01.rfa (wall-based)
│   └── Window_02.rfa (wall-based)
├── Doors\
│   └── Door_01.rfa (wall-based)
├── Furniture\
│   ├── Chair.rfa (standalone)
│   └── Table.rfa (standalone)
└── Lighting\
    ├── Pendant_Light.rfa (ceiling-based)
    └── Wall_Sconce.rfa (wall-based)
```

**Шаги:**
1. RFAtoIFC → ConvertRFA
2. Выберите папку: `C:\Mixed_Families`
3. Выберите папку экспорта: `C:\Export\Mixed`

**Что происходит:**
- Скрипт автоматически определяет тип каждого семейства
- Window_01, Window_02, Door_01, Wall_Sconce → загружаются в проект со стеной
- Chair, Table → загружаются в пустой проект
- Pendant_Light → загружается в проект с потолком

**Результат:**
```
C:\Export\Mixed\
└── IFC4\
    ├── Window_01.ifc
    ├── Window_02.ifc
    ├── Door_01.ifc
    ├── Chair.ifc
    ├── Table.ifc
    ├── Pendant_Light.ifc
    └── Wall_Sconce.ifc
```

### Сценарий 5: Конвертация для архитектурной визуализации в Blender

**Задача:** Подготовить высокодетализированные семейства интерьера для финального рендеринга в Blender Cycles.

**Особенности:**
- Важны материалы и текстуры
- Нужна высокая детализация геометрии

**Подготовка в Revit (перед конвертацией):**

1. **Проверьте материалы:**
   - Откройте каждое семейство в Revit
   - Убедитесь, что материалы назначены
   - Проверьте визуальные свойства (Appearance):
     - Цвет
     - Прозрачность
     - Отражение (если есть)
   - Для текстур: убедитесь, что Image файлы доступны

2. **Оптимизация геометрии:**
   - Используйте Solid Geometry (не Void Forms для визуализации)
   - Проверьте Detail Level в семействе

3. **Конвертация:**
   - RFAtoIFC → ConvertRFA
   - Выберите папку с семействами
   - Экспорт

4. **Импорт в Blender:**
   ```python
   # В Blender используйте BlenderBIM Add-on
   File → Import → Industry Foundation Classes (.ifc)

   # Настройки импорта:
   - Import Type: IFC4
   - Import Materials: ✓ Enabled
   - Import Curves: ✓ Enabled
   ```

5. **Настройка материалов в Blender:**
   - Материалы будут импортированы с базовыми цветами
   - Доработайте в Shader Editor:
     - Добавьте Principled BSDF
     - Настройте Roughness, Metallic
     - Подключите текстуры при необходимости

**Пример скрипта Blender для пост-обработки:**
```python
import bpy

# Скрипт для улучшения импортированных материалов
for mat in bpy.data.materials:
    if mat.use_nodes:
        nodes = mat.node_tree.nodes

        # Найти Principled BSDF
        for node in nodes:
            if node.type == 'BSDF_PRINCIPLED':
                # Настройка для архитектурной визуализации
                node.inputs['Roughness'].default_value = 0.4
                node.inputs['Specular'].default_value = 0.5
```

### Сценарий 6: Обработка ошибок и восстановление

**Задача:** Конвертация большой библиотеки (500+ файлов) с обработкой ошибок.

**Проблема:** Некоторые файлы могут быть повреждены или несовместимы.

**Стратегия:**

1. **Первый проход - конвертация всех:**
   ```
   RFAtoIFC → ConvertRFA
   Выбрать папку: C:\Large_Library
   Экспорт: C:\Export\First_Pass
   ```

2. **Анализ результатов:**
   - Откройте консоль pyRevit
   - Найдите секцию "ИТОГИ КОНВЕРТАЦИИ"
   - Проверьте список ошибок

3. **Пример вывода:**
   ```
   ============================================================
   ИТОГИ КОНВЕРТАЦИИ
   ============================================================
   Всего файлов: 512
   Успешно: 495
   Ошибок: 17

   Ошибки:
     - Ошибка обработки 'Old_Family_v2020.rfa': Не удалось открыть файл
     - Ошибка обработки 'Corrupted.rfa': Не удалось открыть файл
     - Ошибка обработки 'Complex_Curtain_Wall.rfa': Ошибка экспорта IFC
     ...
   ```

4. **Обработка проблемных файлов:**
   - Скопируйте список проблемных файлов
   - Откройте каждый в Revit вручную
   - Попробуйте:
     - Сохранить с новым именем
     - Упростить геометрию
     - Обновить до Revit 2024
     - Пересоздать проблемные элементы

5. **Повторная конвертация:**
   - Исправленные файлы положите в отдельную папку
   - Запустите конвертацию снова только для них

**Советы:**
- Сохраняйте лог консоли (Copy из pyRevit Console)
- Создайте резервную копию оригинальных файлов
- Ведите список проблемных файлов в Excel/CSV

## Типичные ошибки и решения

### Ошибка: "Не удалось открыть файл как семейство"

**Причина:** Файл создан в более новой версии Revit.

**Решение:**
1. Откройте файл в Revit 2024
2. File → Save As → сохраните снова
3. Попробуйте конвертацию еще раз

---

### Ошибка: "Шаблон проекта для типа 'wall' не найден"

**Причина:** Файл шаблона перемещен или удален.

**Решение:**
1. RFAtoIFC → Settings
2. Обновите путь к Wall Template
3. Сохранить

---

### Предупреждение: "3D вид не найден, но продолжаем экспорт"

**Причина:** В шаблоне проекта нет 3D вида.

**Решение:**
1. Откройте шаблон в Revit
2. View → 3D View → Default 3D View
3. Сохраните шаблон
4. Обновите путь в Settings

**Влияние:** IFC будет экспортирован, но может не содержать всю геометрию.

## Интеграция с другими инструментами

### Blender Python API

Автоматизация импорта в Blender:

```python
import bpy
import os

ifc_folder = "C:/Export/IFC4"

for file in os.listdir(ifc_folder):
    if file.endswith('.ifc'):
        filepath = os.path.join(ifc_folder, file)

        # Импорт IFC
        bpy.ops.import_ifc.bim(filepath=filepath)

        # Ваша обработка...
        # - настройка материалов
        # - настройка освещения
        # - рендеринг

        # Сохранить как .blend
        blend_path = filepath.replace('.ifc', '.blend')
        bpy.ops.wm.save_as_mainfile(filepath=blend_path)

        # Очистить сцену для следующего
        bpy.ops.object.select_all(action='SELECT')
        bpy.ops.object.delete()
```

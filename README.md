# RFA to IFC4 Converter

Скрипт для автоматической конвертации файлов семейств Revit (.rfa) в формат IFC4 с оптимизированными настройками для импорта в Blender.

## Возможности

- ✅ Конвертация одного файла .rfa или целой папки
- ✅ Автоматическое определение типа семейства (wall-based, floor-based, ceiling-based, roof-based, standalone)
- ✅ Загрузка семейства в соответствующий проект-шаблон с нужными плоскостями
- ✅ Размещение семейства на 3D-виде перед экспортом
- ✅ Экспорт в IFC4 с правильными настройками для Blender (включая материалы)
- ✅ Автоматическая обработка всплывающих предупреждений Revit
- ✅ Симуляция активности для предотвращения мигания иконки в панели задач
- ✅ Подробная статистика и отчет об ошибках

## Требования

### Программное обеспечение

- **Autodesk Revit 2024** (можно адаптировать под другие версии)
- **pyRevit** - бесплатное расширение для Revit ([скачать здесь](https://github.com/eirannejad/pyRevit/releases))

### Шаблоны проектов

Вам необходимо подготовить 5 файлов проектов Revit (.rvt) с базовыми элементами:

1. **Проект со стеной** - для семейств, требующих стену (окна, двери, настенные светильники и т.д.)
2. **Проект с полом** - для семейств на полу (мебель, колонны, сантехника и т.д.)
3. **Проект с потолком** - для семейств на потолке (потолочные светильники и т.д.)
4. **Проект с крышей** - для семейств на крыше (кровельные элементы и т.д.)
5. **Пустой проект** - для standalone семейств, не требующих специальных плоскостей

## Установка

### 1. Установка pyRevit

1. Скачайте последнюю версию pyRevit: https://github.com/eirannejad/pyRevit/releases
2. Запустите установщик и следуйте инструкциям
3. Перезапустите Revit после установки

### 2. Установка скрипта

1. Найдите папку установки pyRevit extensions. Обычно это:
   ```
   C:\Users\<Имя пользователя>\AppData\Roaming\pyRevit\Extensions
   ```
   Или используйте pyRevit CLI:
   ```
   pyrevit extensions paths
   ```

2. Скопируйте папку `RFAtoIFC.extension` в папку extensions:
   ```
   C:\Users\<Имя пользователя>\AppData\Roaming\pyRevit\Extensions\RFAtoIFC.extension
   ```

3. Перезагрузите pyRevit:
   - В Revit откройте вкладку **pyRevit**
   - Нажмите **Reload** (иконка со стрелками)

4. После перезагрузки вы увидите новую вкладку **RFAtoIFC** с панелью **Convert** и двумя кнопками:
   - **Settings** - настройка путей к шаблонам
   - **ConvertRFA** - запуск конвертации

## Настройка

### Подготовка шаблонов проектов

1. Создайте 5 проектов Revit (.rvt) с базовыми элементами:

   **Проект со стеной:**
   - Создайте базовую стену (например, Generic - 200mm)
   - Стена должна быть достаточно большой для размещения семейств
   - Рекомендуемые размеры: длина 6000 мм, высота 3000 мм

   **Проект с полом:**
   - Создайте базовый пол (например, Generic - 150mm)
   - Рекомендуемые размеры: 6000 x 6000 мм

   **Проект с потолком:**
   - Создайте базовый потолок (например, Compound Ceiling - 400mm)
   - Рекомендуемые размеры: 6000 x 6000 мм

   **Проект с крышей:**
   - Создайте базовую крышу
   - Рекомендуемые размеры: 6000 x 6000 мм

   **Пустой проект:**
   - Создайте пустой проект с одним уровнем
   - Настройте единицы измерения по вашим предпочтениям

2. Сохраните все проекты в удобную папку, например:
   ```
   C:\Revit Templates\RFA Conversion\
   ```

### Настройка путей к шаблонам

1. Запустите Revit
2. Откройте вкладку **RFAtoIFC**
3. Нажмите кнопку **Settings**
4. В открывшемся окне укажите пути к каждому из 5 шаблонов:
   - Нажмите кнопку **"..."** рядом с каждым типом
   - Выберите соответствующий .rvt файл
5. Нажмите **Сохранить**

Настройки сохраняются в файл:
```
<папка с RFAtoIFC.extension>/config/templates_config.json
```

## Использование

### Запуск конвертации

1. Откройте Revit (можно с любым проектом или без проекта)
2. Откройте вкладку **RFAtoIFC**
3. Нажмите кнопку **ConvertRFA**
4. Выберите, что вы хотите конвертировать:
   - **Выбрать файл .rfa** - конвертация одного файла
   - **Выбрать папку с .rfa файлами** - конвертация всех файлов .rfa в папке (включая подпапки)
5. Выберите папку для экспорта IFC файлов
6. Дождитесь завершения процесса

### Результаты экспорта

После конвертации в выбранной папке будет создана подпапка:
```
<Выбранная папка>/
└── IFC4/
    ├── Family1.ifc
    ├── Family2.ifc
    └── ...
```

Все IFC файлы сохраняются в одну общую папку **IFC4**.

### Процесс конвертации

Для каждого файла .rfa скрипт выполняет:

1. **Открытие файла семейства**
2. **Анализ типа семейства** - определение требуемого типа host (wall/floor/ceiling/roof/standalone)
3. **Загрузка соответствующего шаблона** - открытие проекта с нужной плоскостью
4. **Загрузка семейства в проект**
5. **Размещение экземпляра семейства** - размещение на 3D-виде
6. **Активация 3D-вида**
7. **Экспорт в IFC4** с оптимизированными настройками:
   - ExportSurfaceStyles = True (экспорт материалов и цветов)
   - ExportBaseQuantities = True (базовые количества)
   - ExportSolidModelRep = True (твердотельные модели)
   - UseVisibleRevitNameAsEntityName = True (понятные имена элементов)
   - FileVersion = IFC4

### Особенности работы с материалами

Скрипт настроен для максимально корректного экспорта материалов в Blender:

- ✅ Экспорт Surface Styles (визуальные стили поверхностей)
- ✅ Экспорт цветов материалов
- ✅ Использование IFC4 (лучшая поддержка визуальных стилей)
- ✅ Экспорт базовых количеств и свойств

**Важно:** В Blender используйте правильный импортер IFC:
- Рекомендуется **BlenderBIM Add-on** (бесплатный): https://blenderbim.org/
- Или встроенный импортер IFC в Blender 3.x+

## Устранение неполадок

### Ошибка: "Шаблоны проектов не настроены"

**Решение:** Запустите **Settings** и укажите пути ко всем 5 шаблонам проектов.

### Ошибка: "Не удалось открыть файл как семейство Revit"

**Причины:**
- Файл поврежден
- Файл создан в более новой версии Revit
- Файл не является семейством (.rfa)

**Решение:** Проверьте файл в Revit вручную.

### Ошибка: "Шаблон проекта для типа '...' не найден"

**Причины:**
- Файл шаблона был перемещен или удален
- Неверный путь в настройках

**Решение:** Откройте **Settings** и обновите путь к шаблону.

### Семейство не размещается в проекте

**Причины:**
- Семейство требует специфический host, который не соответствует шаблону
- Семейство имеет особые параметры размещения

**Решение:**
- Проверьте, правильно ли определен тип семейства
- Убедитесь, что в шаблоне есть подходящий элемент (стена/пол/потолок/крыша)
- При необходимости измените логику определения типа в `family_analyzer.py`

### Материалы не импортируются в Blender

**Возможные причины:**
- Неправильный импортер IFC в Blender
- Материалы не назначены в Revit

**Решение:**
1. Используйте **BlenderBIM Add-on** для импорта IFC
2. В Revit проверьте, что материалы назначены элементам семейства
3. Убедитесь, что материалы имеют визуальные свойства (цвет, текстура)

### Revit мигает в панели задач

Скрипт включает симулятор активности, который должен предотвращать это. Если проблема сохраняется:
- Убедитесь, что Revit находится на переднем плане во время конвертации
- Отключите фокус других приложений

## Технические детали

### Определение типа семейства

Скрипт анализирует следующие параметры:
- `FamilyPlacementType` - тип размещения семейства
- `BuiltInCategory` - встроенная категория семейства
- `Work Plane-Based` - параметр привязки к рабочей плоскости

### Настройки экспорта IFC4

Ключевые параметры для Blender:
```python
ifc_options.FileVersion = IFCVersion.IFC4
ifc_options.ExportSurfaceStyles = True      # Материалы!
ifc_options.ExportBaseQuantities = True
ifc_options.ExportSolidModelRep = True
ifc_options.UseVisibleRevitNameAsEntityName = True
```

### Обработка предупреждений

Скрипт использует `IFailuresPreprocessor` для автоматической обработки:
- **Warnings** - автоматически удаляются
- **Errors** - пытается разрешить через `ResolveFailure`, если невозможно - удаляет

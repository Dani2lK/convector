# Changelog

Все важные изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2024-11-06

### Добавлено

#### Основной функционал
- Конвертация .rfa файлов в IFC4 формат
- Поддержка пакетной обработки (выбор папки)
- Поддержка одиночных файлов
- Автоматическое определение типа семейства:
  - Wall-based (окна, двери, настенные элементы)
  - Floor-based (мебель, колонны, напольные элементы)
  - Ceiling-based (потолочные светильники, вентиляция)
  - Roof-based (кровельные элементы)
  - Standalone (отдельностоящие элементы)

#### Экспорт IFC4
- Оптимизированные настройки экспорта для Blender
- Поддержка экспорта материалов (Surface Styles)
- Экспорт визуальных представлений
- Экспорт базовых количеств
- Использование твердотельной геометрии
- Понятные имена элементов

#### UI и пользовательский интерфейс
- GUI для настройки путей к шаблонам проектов
- GUI для выбора файла/папки .rfa
- GUI для выбора папки экспорта
- Русскоязычный интерфейс
- Диалоги подтверждения

#### Обработка ошибок
- Автоматическая обработка предупреждений Revit
- Автоматическое закрытие диалогов ошибок
- Подробное логирование в pyRevit Console
- Статистика успешных/неудачных конвертаций
- Список ошибок с деталями

#### Конфигурация
- Сохранение настроек в JSON
- Запоминание последних используемых папок
- Конфигурация путей к 5 типам шаблонов

#### Оптимизация
- Симуляция активности Revit для предотвращения мигания иконки
- Эффективная обработка множественных файлов
- Автоматическое закрытие документов после обработки

#### Документация
- Подробное руководство (README.md)
- Инструкция по установке (INSTALLATION.md)
- Примеры использования (USAGE_EXAMPLES.md)
- Этот файл изменений (CHANGELOG.md)

### Технические детали

#### Модули
- `config_manager.py` - управление конфигурацией
- `family_analyzer.py` - анализ типа семейства
- `ifc_exporter.py` - экспорт в IFC4
- `ui_helpers.py` - UI компоненты и диалоги

#### Кнопки pyRevit
- **Settings** - настройка путей к шаблонам
- **ConvertRFA** - главная функция конвертации

#### Требования
- Autodesk Revit 2024
- pyRevit 4.8+
- .NET Framework 4.8+

### Известные ограничения

- Требуется ручное создание шаблонов проектов
- Некоторые сложные семейства могут требовать ручной доработки
- Текстуры экспортируются как цвета (без изображений)
- In-place families не поддерживаются

## Формат версий

**MAJOR.MINOR.PATCH** (например, 1.0.0)

- **MAJOR** - несовместимые изменения API
- **MINOR** - новый функционал с обратной совместимостью
- **PATCH** - исправления багов с обратной совместимостью

## Типы изменений

- **Добавлено** - новый функционал
- **Изменено** - изменения в существующем функционале
- **Устарело** - функционал, который скоро будет удален
- **Удалено** - удаленный функционал
- **Исправлено** - исправления багов
- **Безопасность** - исправления уязвимостей

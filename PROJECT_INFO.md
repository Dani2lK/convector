# RFA to IFC4 Converter - Информация о проекте

## Описание

**RFA to IFC4 Converter** - это расширение pyRevit для автоматической конвертации файлов семейств Autodesk Revit (.rfa) в формат IFC4 с оптимизированными настройками для импорта в Blender.

## Цель проекта

Упростить процесс переноса BIM-контента из Revit в Blender для:
- Архитектурной визуализации
- Создания библиотек 3D моделей
- Веб-визуализации
- Игровых движков
- AR/VR приложений

## Ключевые особенности

### Автоматизация
- Пакетная обработка множества файлов
- Автоматическое определение типа семейства
- Автоматический выбор соответствующего шаблона проекта
- Автоматическое размещение на 3D-виде

### Совместимость с Blender
- Экспорт материалов и цветов
- Оптимизированная геометрия
- Правильная структура IFC
- Поддержка BlenderBIM Add-on

### Удобство использования
- Простой GUI интерфейс
- Русскоязычный интерфейс
- Подробное логирование
- Статистика и отчеты об ошибках

## Технический стек

- **Язык:** Python 2.7 (IronPython в Revit)
- **Платформа:** pyRevit
- **API:** Revit API 2024
- **UI:** Windows Forms (.NET)
- **Формат экспорта:** IFC4 (ISO 16739:2018)

## Процесс конвертации

```
1. Выбор файла(ов) .rfa
          ↓
2. Анализ типа семейства
          ↓
3. Выбор шаблона проекта
          ↓
4. Загрузка семейства в проект
          ↓
5. Размещение на 3D-виде
          ↓
6. Экспорт в IFC4
          ↓
7. Сохранение в папку IFC4
```

## Поддерживаемые типы семейств

| Тип | Описание | Пример |
|-----|----------|--------|
| Wall-based | Семейства на стене | Окна, двери, настенные светильники |
| Floor-based | Семейства на полу | Мебель, колонны, сантехника |
| Ceiling-based | Семейства на потолке | Потолочные светильники, вентиляция |
| Roof-based | Семейства на крыше | Кровельные элементы, фонари |
| Standalone | Отдельностоящие | Generic Models, оборудование |

## Ограничения

### Текущие ограничения
- Только IFC4 (IFC 2x3 не поддерживается)
- Текстуры экспортируются только как цвета
- In-place families не поддерживаются
- Требуется ручное создание шаблонов

### Известные проблемы
- Некоторые сложные curtain wall families могут экспортироваться некорректно
- Adaptive components требуют доработки
- Вложенные семейства экспортируются как единый объект
